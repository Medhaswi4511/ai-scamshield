# AI ScamShield

AI-powered scam and phishing detection platform that analyzes suspicious messages and URLs in real time.

## Problem

Online scams and phishing attacks are increasing rapidly, and users often fail to identify malicious content before interacting with it.

## Solution

AI ScamShield detects suspicious:

* Messages
* Phishing URLs

It assigns:

* Risk score
* Threat classification
* Explainable detection reasons

## Features

* Message Scam Detection
* URL Phishing Detection
* Real-time Risk Scoring
* Explainable AI Results
* Modern Interactive Dashboard

## Tech Stack

### Frontend

* Next.js
* TypeScript
* Tailwind CSS

### Backend

* FastAPI
* Python

## How It Works

1. User enters suspicious message or URL
2. Backend analyzes keywords and patterns
3. Risk score is calculated
4. Threat explanation is displayed
